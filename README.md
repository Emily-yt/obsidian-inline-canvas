# Inline Canvas

一个让你在 Obsidian 笔记中快速插入流程图的插件。右键即可自动创建白板、嵌入当前位置，并在侧边打开官方 Canvas 编辑器。

## 功能

- 在笔记编辑区右键选择“插入流程图白板”，或通过命令面板执行。
- 新白板默认只有一个卡片，文字为“请在此输入内容”。
- 自动在光标位置插入白板预览，不替换选中文字。
- 使用官方 Canvas 在侧边编辑，修改自动保存。
- 阅读模式下可通过“编辑流程图”按钮再次打开白板。
- 新白板保存到笔记同级的 `Flowcharts` 文件夹。
- 为 `.canvas` 嵌入创建只读的官方 Canvas 视图，保留标题、字体、Markdown、主题颜色和连线样式。
- 白板或引用的笔记保存后自动刷新预览；已有的 `.canvas` 嵌入无需改写链接。
- 预览接入笔记阅读模式、实时预览和原生 Slides 的 Markdown 渲染流程。

## 安装

1. 在 Obsidian 仓库中创建 `.obsidian/plugins/inline-canvas/` 文件夹。
2. 将本仓库的 `main.js`、`manifest.json` 和 `styles.css` 放入该文件夹。
3. 重启 Obsidian，在“设置 → 第三方插件”中启用 **Inline Canvas**。
4. 确保“设置 → 核心插件 → 白板”已启用。

无需编译。插件目前尚未上架 Obsidian 社区插件目录，需要手动安装。

## 使用

1. 打开 Markdown 笔记，进入编辑模式，把光标放在插入位置。
2. 右键选择“插入流程图白板”，或者按 `Ctrl+P`，搜索“Inline Canvas: 插入流程图白板”。
3. 在侧边打开的白板中双击初始卡片，修改“请在此输入内容”。
4. 双击空白处添加更多卡片，从卡片边缘拖出连线。
5. 回到笔记，在实时预览或阅读模式下查看流程图；阅读模式下点击“编辑流程图”可再次编辑。

源码模式中显示嵌入链接。白板文件也可在文件列表中右键，选择“在旁边编辑流程图”。

## 版本与验证

当前版本为 **0.5.3 实验版**。

用户已在 Obsidian 中测试并确认 0.1.0 的基本流程可用。0.3.0 改用官方 Canvas 视图，已通过语法、只读保护、刷新和资源清理的模拟测试。本次原生预览在笔记及 Slides 中的实际效果仍需用户复验，移动端兼容性尚未验证。

正文中的白板是预览，编辑在侧边进行。重复点击编辑可能增加分栏。

## 包含文字的嵌入预览

继续使用原有的嵌入写法，例如 `![[Flowcharts/示例.canvas]]`。插件启用后会显示只读的官方 Canvas 视图，保留原生卡片、Markdown 标题和文字、颜色与连线样式。

预览宽高根据卡片范围自动调整，较长白板限制显示高度。初始缩放不低于 85%，避免为塞入整个大白板而把文字缩得过小；宽白板可能需要平移查看。可通过“放大”“缩小”“原始大小”“适应画面”按钮调整视图，也可使用 Canvas 原生的鼠标平移和缩放操作。

保存后预览会刷新，并保留当前视角。预览只读，修改内容请点击“编辑流程图”。原生 Canvas 会依据实际可见区域加载卡片内容；插件关闭了缩小时隐藏文字的阈值。包含递归 Canvas 的嵌入不会被本插件继续展开。

此功能使用经过检查的 Canvas 内部视图接口，没有全局修改 Canvas 原型。Obsidian 更新后可能需要适配；接口不兼容或预览失败时会显示提示并恢复原生简略预览。停用插件也会恢复原生嵌入。

## 0.4.0：自动尺寸

文字卡片保留宽度，按照原生 Markdown 内容自动调整高度，最小高度 64 像素。修改保存回原白板，增高时顺移同列下方可能重叠的卡片。文件卡片和分组不自动调整。

预览按内容调整宽高，可点击“自动调整大小”。白板中也可执行命令“根据内容调整文字卡片大小”。已通过尺寸、避让、重复执行、并发保护及预览生命周期模拟测试，实际界面效果仍需复验。

## 0.5.0：自动宽度与预览边界

文字卡片根据原生 Markdown 内容自动调整宽高，宽度限制为 180–560 像素，长文本会换行。增宽时顺移同排右侧可能重叠的卡片。此修改保存回原白板。

笔记预览的平移限制在流程图内容边界附近，保留 24 像素边距；内容小于窗口时自动居中。实际 Obsidian 界面效果仍需复验。


## 0.5.1：保留手动尺寸

手动拖动修改宽度后，插件保留该宽度；手动修改高度后，插件保留该高度。宽高分别判断，未手动修改的一项继续自动调整。选择会保存在白板卡片的 inlineCanvasSizing 字段中，重新打开白板或重启插件后仍然有效。


## 0.5.2：避免编辑干扰

拖动期间暂停尺寸调整和预览刷新；等待原生编辑器保存后再调整。仅文字变化才重新测量，颜色和位置变化不会触发尺寸重算。有编辑器打开时，嵌入预览不写入原白板，避免两个视图同时修改文件。


## 0.5.3：精简预览工具栏

画布下方右侧仅保留编辑、放大、缩小三个图标按钮，支持悬停提示和无障碍名称。
